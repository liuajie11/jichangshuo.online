    TX

    文本与研究

    写作、搜索、总结、深度推理与跨语言知识整理。

    ChatGPT TOP 1 官网 ↗
    应用：全能通用对话、长文创作、复杂学术分析与多模态交互。
    功能：GPT-4o 多模态理解、高级语音模式、联网搜索与自定义 GPTs。
    优点：生态最完善、通用泛化能力最强，支持海量插件与移动端原生交互。
    Claude TOP 2 官网 ↗
    应用：深度长文本阅读、长篇写作、逻辑论证与代码逻辑分析。
    功能：Claude 3.5 Sonnet 模型、200K 超长上下文窗口、Artifacts 交互画布。
    优点：文风自然细腻最接近真人思维，长文本召回率极高，代码生成首选。
    Perplexity TOP 3 官网 ↗
    应用：学术文献调研、实时信息溯源、行业情报检索与事实核验。
    功能：对话式搜索引擎、Copilot 交互引导、自动标注引文证据与来源。
    优点：无广告直接输出结构化答案，信息可信度高，大幅提升检索效率。

    IM

    图像与设计

    图像生成、画面精修、商业视觉设计与概念原型。

    Midjourney TOP 1 官网 ↗
    应用：商业插画设计、概念艺术设定、电商视觉图与摄影级写实渲染。
    功能：V6 高精图像生成、局部重绘(Inpainting)、图生图及参数化风格调优。
    优点：艺术审美水准业界天花板，光影与材质细节逼真，提示词理解精准。
    Stable Diffusion TOP 2 官网 ↗
    应用：专业画师工作流、企业私有化部署、游戏模型资产与可控出图。
    功能：开源大模型生图、ControlNet 精确姿态构图控制、LoRA 微调模型加载。
    优点：开源免费、离线私密运行、生态扩展插件极强、拥有极致的可控度。
    Magnific AI TOP 3 官网 ↗
    应用：超分辨率放大、老照片质感增强、3D 渲染图细节二次超高清重建。
    功能：幻觉式高倍放大(Upscale)、重构皮肤毛孔与微纹理、风格重构。
    优点：画面放大后不仅清晰更具全新丰富细节，被影视与游戏视效行业推崇。

    VD

    视频与音频

    文字生成视频、音效配乐创作、无损配音与影视制作。

    Runway TOP 1 官网 ↗
    应用：影视级 AI 视频生成、特效合成、广告创意短片与动画分镜制作。
    功能：Gen-3 Alpha 视频大模型、摄像机镜头轨迹控制、局部动态笔刷。
    优点：镜头运动平滑逼真、物理动力学规律优秀，影视创意专业人士标配。
    Suno TOP 2 官网 ↗
    应用：歌曲作词作曲、商业广告配乐、游戏 BGM 创作与自媒体背景音乐。
    功能：V3.5 音乐大模型、输入文字即生成含人声歌词与完整编曲的单曲。
    优点：零门槛创作专业级音乐、涵盖流行摇滚爵士全曲风，伴奏演唱浑然天成。
    ElevenLabs TOP 3 官网 ↗
    应用：有声书朗读、短视频解说配音、游戏角色拟真配音与声音克隆。
    功能：高逼真情感语音合成(TTS)、几秒样本极速声音克隆、AI 音效生成。
    优点：声音抑扬顿挫有呼吸感与情感起伏，支持数十种多语言无缝同声传译。

    CD

    编程与开发

    智能代码编写助手、全局项目重构、Bug 修复与自动化测试。

    Cursor TOP 1 官网 ↗
    应用：全栈项目开发、从零快速搭建全套应用、复杂工程全局重构。
    功能：基于 VS Code 的深度定制 IDE、Composer 多文件跨代码库协同编辑。
    优点：深度理解项目全局上下文、代码补全响应极快，被誉为程序员提效神器。
    GitHub Copilot TOP 2 官网 ↗
    应用：日常行级代码补全、测试用例自动编写、开源仓库代码解读。
    功能：IDE 插件式内联补全、Copilot Chat 问答、GitHub Workspace 自动化集成。
    优点：生态与各大 IDE 兼容极佳、背靠微软与 GitHub 社区海量代码库支撑。
    v0 (Vercel) TOP 3 官网 ↗
    应用：前端 UI 原型快速生成、网页布局开发、React/Tailwind 代码输出。
    功能：通过自然语言直接生成现代化前端组件，支持即时预览与复制代码。
    优点：生成界面审美极高、开箱即用的现代化代码、大幅缩短前端产品落地时间。

    OF

    办公与协作

    智能会议转录纪要、文档知识库搭建、演示文稿与团队工作流。

    Notion AI TOP 1 官网 ↗
    应用：团队企业知识库搭建、项目进度追踪、会议笔记自动整理与润色。
    功能：全空间跨页面智能问答 Q&A、自动化表格属性提炼、文案翻译改写。
    优点：无缝融入 Notion 笔记体系、直接索引全局工作资料，无需频繁切换应用。
    Otter.ai TOP 2 官网 ↗
    应用：跨国远程视频会议、商务会谈现场记录、课程录音整理与待办提取。
    功能：实时多说话人语音转文字、自动提炼会议核心摘要与行动代办项(Action Items)。
    优点：深度打通 Zoom/Teams/Google Meet，开会不用分心做笔记，准确率极高。
    Gamma App TOP 3 官网 ↗
    应用：商业路演 PPT 快速制作、项目方案汇报排版、网页互动式文档展示。
    功能：一句话或提纲一键生成精美演示文稿(PPT)、网页和排版文档。
    优点：告别传统 PPT 排版痛苦，卡片式现代视觉风格极具设计感，支持交互嵌入。

    AP

    聚合与导航

    多模型一键聚合、全球 API 统一路由与原生多模态客户端。

    Poe by Quora TOP 1 官网 ↗
    应用：一站式同时体验全球最顶尖主流 AI 模型、自制个性化专属机器人。
    功能：聚合 ChatGPT、Claude 3.5、Gemini 1.5 Pro、FLUX 绘图等上百种模型。
    优点：一个订阅会员即可无限制切换全球头部模型，iOS/Android/Web 体验极佳。
    OpenRouter TOP 2 官网 ↗
    应用：开发者一站式统一 API 调用、按需自动负载均衡与最低延迟路由。
    功能：提供与 OpenAI 规范完全兼容的单一直连 API 接口，汇总数百款开源与商用模型。
    优点：充值一次通兑全球模型、费率完全透明无套路、自动故障转移保障服务不断线。
    Chatbox TOP 3 官网 ↗
    应用：本地桌面端多模型办公对话、本地数据隐私保护、个人自用 API 客户端。
    功能：支持自定义接入 OpenAI / Claude / Ollama 本地模型、Markdown 与代码高亮。
    优点：全开源跨平台桌面端应用(Win/Mac/Linux/移动端)、数据存储本地绝不泄密。
